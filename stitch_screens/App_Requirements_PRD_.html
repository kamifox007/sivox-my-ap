# Party/Club Booking App – Stitch UI/UX Design ## 1. User Roles & Flows ### Visitor Flow - **Role Selection:** User chooses "Visitor". - **Registration/Login:** Mock authentication screens. - **Home Screen:** List of events with "View Details". - **Event Details:** Info, location, booking type (Free/Pay at Venue), and a guest count selector. - **Booking / QR Screen:** Centralized QR code, booking summary, and a "Share QR" feature. ### Organizer / Owner Flow - **Role Selection:** User chooses "Owner/Organizer". - **Register Club:** Setup screen for venue details. - **Organizer Dashboard:** Manage events list. - **Edit Event Screen:** Update name, images, date, location, and booking type. - **View Bookings Screen:** Manage guest list and entry status. ### Doorman / Entry Flow - **Scan QR:** Mock scanner interface. - **Booking Details (Post-Scan):** Validation screen showing user name, people count, and booking type. - **Confirm Entry:** Action to update entry counter. ## 2. Key Features & UI Requirements - **Instagram-like UI:** Clean, fast, and visual. - **Booking Logic:** Support for "Free" vs "Pay at Venue". - **Navigation:** Smooth transitions between core flow screens. - **Visuals:** High-visibility QR codes and "Nocturnal" dark mode styling. ## 3. Technical Notes (Mock-only) - Purely UI/UX focus. - No real database or payment integration. - Fast comprehension (<5 seconds per screen).
